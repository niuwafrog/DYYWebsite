# 奶奶的房间 · a room, kept

一个可以走进去的数字纪念：客厅、厨房、旧照片，和一些还留在这里的声音。

> An interactive memorial. Hand-drawn rooms (Procreate) + real family photographs and
> voice recordings. Everything visitors see comes from `data/content.js` — you don't
> need to touch the code.

## 怎么打开

- **直接双击 `index.html`** 就能看（不需要服务器、不需要联网）。
- 想用本地服务器（导出拼贴图必须要它）：

  ```bash
  python -m http.server 8000
  # 然后打开 http://localhost:8000
  ```

## 1. 换成 Procreate 画的房间

1. 画布按 **16:9** 画，导出 **3200×1800** 的 PNG（或 JPG，质量 85%）。
   尺寸大一点，之后放大看细节才不会糊。
2. 存成 `assets/art/living-room.png`、`assets/art/kitchen.png`（名字随意）。
3. 打开 `data/content.js`，改 `scenes.living.art` 和 `scenes.kitchen.art` 的路径，
   顺便把 `alt` 改成这句描述（给看不见图的人听的）。
4. 如果某个时间段换了另一张图（比如夜里那版），改 `phases[n].art` 里的对应路径。

> 画的时候记住：物件彼此留一点空隙，点击圈不会互相打架；
> 重要物件不要贴着边缘放，手机上边缘会被裁掉一点。

## 2. 放上可点的物件

1. 浏览器打开 `tools/hotspot-editor.html`，把房间图拖进去。
2. 在图上点一下物件 → 右侧出现一行，填名字、选类型（故事 / 奶奶 / 换房间）。
3. 拖圆点可以微调位置；`d` 是圈的大小。
4. 点"复制"，把 JSON 粘进 `data/content.js` 里对应的 `hotspots: [ ... ]`，再把故事文字补上。

三个字段的含义：

- `x, y` — 物件中心点，整张图的百分比（左上角是 0,0）
- `d` — 点击圈直径，图宽的百分比（10 就是图宽的十分之一）
- `kind` — `memory` 打开故事 / `granny` 和奶奶说话 / `scene` 走到另一个房间

## 3. 录音和照片

- **录音**：手机录的 `.m4a` 或导出的 `.mp3` 都能用，放进 `assets/audio/`，
  在故事里写 `audio: "assets/audio/xxx.mp3"`。
  有录音的故事**一定**把 `transcript` 写上——老人说话轻、有口音、有杂音，
  很多人会先读字；这也是将来听不清时的备份。
- **照片**：扫描或翻拍都行，长边 1600px 左右够了。放进 `assets/photos/`。
  每张照片可以写 `caption` 和 `year`，会显示在图下面。

## 4. 房间怎么随时间变

`data/content.js` 里的 `phases`：

```js
{ id: "dusk", after: 3, overlay: "dusk", granny: "这个点光最好看。", art: {...} }
```

`after: 3` = 看到 3 段记忆之后切到这一段。想按"年份"而不是"一天里的时间"来变，
就把 `after` 当成解锁几段记忆的进度，`granny` 台词写成那个年代的口气。

光线的颜色在 `styles/style.css` 里找 `body[data-phase="dusk"] .scene__light`。

## 5. 照片桌

访客在故事里看到的照片，会出现在照片桌上，可以拖、缩放、旋转、拼成一版。
摆放存在**访客自己的浏览器**里（localStorage），不会传到任何服务器。

导出 PNG 需要 `http://`（直接在 `file://` 下打开时浏览器会拒绝导出，页面会提示）。

### 关于隐私（值得先想一下）

这里面有真实的家人照片和声音。上线前想清楚：

- 只发给家人的话，用 Netlify/Cloudflare 的**密码保护**，或用一个猜不到的网址。
- 想公开的话，先问问照片里其他人（尤其是小孩）愿不愿意。
- 别把原始录音的高清文件放在公开仓库里，用压缩过、短一点的版本。

## 写内容的一点建议

这类页面最容易变成"悼词加背景音乐"。几个更有效的做法：

1. **写具体的动作，不写评价。** "她择菜的时候听到要紧处手就停下来"比"她很慈祥"有用得多。
2. **留一件想不通的事。** 为什么留着那张票据、为什么坚持留半瓶水——不解释反而更像真人。
3. **别让人一次看完。** 现在按"看到几段记忆"推进时间，就是为了给访客一个停下来的理由。
4. **声音只用一处。** 到处都有声音会让人关掉；一段关键的话单独出现才有分量。
5. **奶奶的台词别写成旁白。** 她应该只回应你做过的事，像 `perMemory` 里那样。

## 已知限制

- 拼贴的"导出图片"和部分音频在 `file://` 下会受浏览器限制，用 `http://localhost` 最稳。
- 时间段的切换是靠"看到几段"算的，没有真实时钟（想做真实时间很容易，改 `phaseFor` 就行）。
- 热点是圆形，形状复杂的物件会有一部分点不到——把 `d` 调大一点就解决了。
- 没有做多语言；文案里的中文直接写在 `content.js`。
